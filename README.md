# CampusMarket

Small online marketplace for students, built week by week for CCS 2314 Web Based Programming II.

## What works so far
- Home, catalog, register and cart pages (HTML/CSS/JS)
- Catalog is built from one list in `products.js`; search and category filter also change the gallery
- Quantities are validated; invalid ones are left out of totals and the reason is shown
- Cart is saved in localStorage: add, change quantity, remove, clear
- Registration form with specific error messages; a successful submit plays an animation
